Migrate any CMake or Gradle project to Bazel in three commands.

<Steps>

1. **Analyze** — See what rebaze detects

   ```bash
   rebaze analyze .
   ```
   ```
   Detected build systems: cmake
   ```

2. **Migrate** — Generate Bazel files

   ```bash
   rebaze migrate .
   ```

   <FileTree>
   - MODULE.bazel
   - BUILD.bazel
   - .bazelversion
   - .bazelrc
   </FileTree>

3. **Build** — Verify it works

   ```bash
   bazel build //...
   ```

</Steps>

Done. Your project now builds with Bazel.

---

## Preview before writing

Use `--dry-run` to see what would be generated:

```bash
rebaze migrate . --dry-run
```

## Customize with config

Create `rebaze.toml` for custom dependency mappings:

```toml
[mappings.system_libraries]
myvendorlib = "@myvendor//:lib"

[strategy]
default = "system"
```

Then migrate:

```bash
rebaze migrate . --config rebaze.toml
```

See [Configuration Reference](/rebaze/reference/config/) for all options, or jump to [Common Recipes](#common-recipes) below.

## Common recipes

### Map an unknown library

```toml
[mappings.system_libraries]
customlib = "@customlib"
```

### Use hermetic builds

```toml
[strategy]
default = "source"
```

### Pin dependency versions

```toml
[versions]
rules_cc = "0.1.1"
googletest = "1.15.2"
```

## Troubleshooting

**"Unknown library 'xyz', skipping"**
→ Add to `[mappings.system_libraries]` in `rebaze.toml`

**Build fails after migration**
→ Check include paths and verify all sources are captured

**Missing dependencies**
→ Run with `--verbose` to see what rebaze detected
