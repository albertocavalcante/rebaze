## Homebrew (macOS/Linux)

The easiest way to install rebaze is via Homebrew using the `albertocavalcante/tap`:

```bash
# Add the tap
brew tap albertocavalcante/tap
```

### Stable (Builds from Source)

```bash
brew install albertocavalcante/tap/rebaze
```

<Aside type="note">
The stable version builds from source, which requires Rust. Homebrew will automatically install Rust as a build dependency. Build time is approximately 5-10 minutes.
</Aside>

### Nightly (Prebuilt Binaries)

The nightly version uses prebuilt binaries and installs instantly. Since rebaze is currently a private repository, you need to authenticate with a GitHub token:

<Tabs>
  <TabItem label="Using GitHub CLI (recommended)">
    ```bash
    # If you have gh installed and authenticated
    export HOMEBREW_GITHUB_API_TOKEN="$(gh auth token)"
    brew install albertocavalcante/tap/rebaze-nightly
    ```
  </TabItem>
  <TabItem label="Using Personal Access Token">
    ```bash
    # Generate a PAT at https://github.com/settings/tokens
    # Required scope: repo (for private repository access)
    export HOMEBREW_GITHUB_API_TOKEN="ghp_your_token_here"
    brew install albertocavalcante/tap/rebaze-nightly
    ```
  </TabItem>
</Tabs>

<Aside type="tip">
Add the export to your shell profile (`~/.zshrc` or `~/.bashrc`) for persistence:
```bash
echo 'export HOMEBREW_GITHUB_API_TOKEN="$(gh auth token)"' >> ~/.zshrc
```
</Aside>

<Aside type="caution">
The stable and nightly versions conflict—uninstall one before installing the other:
```bash
brew uninstall rebaze
brew install albertocavalcante/tap/rebaze-nightly
```
</Aside>

### Update & Uninstall

```bash
# Update to latest version
brew upgrade rebaze   # or rebaze-nightly

# Uninstall
brew uninstall rebaze

# Remove the tap entirely
brew untap albertocavalcante/tap
```

## Build from Source

rebaze is built with Bazel. Clone the repository and build:

```bash
git clone https://github.com/albertocavalcante/rebaze.git
cd rebaze
bazel build //crates/rebaze-cli:rebaze
```

The binary will be at:
```
bazel-bin/crates/rebaze-cli/rebaze
```

## Add to PATH

<Tabs>
  <TabItem label="macOS/Linux">
    ```bash
    # Option 1: Symlink to a directory in PATH
    sudo ln -s $(pwd)/bazel-bin/crates/rebaze-cli/rebaze /usr/local/bin/rebaze

    # Option 2: Add to PATH in your shell profile
    echo 'export PATH="$PATH:/path/to/rebaze/bazel-bin/crates/rebaze-cli"' >> ~/.zshrc
    source ~/.zshrc
    ```
  </TabItem>
  <TabItem label="Windows">
    ```powershell
    # Add to user PATH
    $env:PATH += ";C:\path\to\rebaze\bazel-bin\crates\rebaze-cli"
    ```
  </TabItem>
</Tabs>

## Verify Installation

```bash
rebaze --version
```

## Requirements

- **Bazel 9.x** - Required for building rebaze and for migrated projects
- **CMake 3.14+** - Optional, for cmake-file-api integration
- **Rust toolchain** - Only needed if building from source with Cargo

<Aside type="note">
rebaze generates Bazel 9 compatible output. Ensure you have Bazel 9.x installed for running the migrated projects.
</Aside>

## Development Setup

If you want to contribute or modify rebaze:

```bash
# Clone with submodules
git clone --recursive https://github.com/albertocavalcante/rebaze.git
cd rebaze

# Build all targets
bazel build //...

# Run tests
bazel test //...

# Format code
cargo fmt

# Run linter
cargo clippy
```
