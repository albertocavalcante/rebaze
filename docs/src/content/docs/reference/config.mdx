Create a `rebaze.toml` in your project root to customize migration behavior.
Omitted mapping fields retain built-in defaults. Supplied maps/lists replace their
field, except source catalog entries merge into the built-in catalog by key; each
supplied source entry replaces that complete entry.

## Common recipes

Copy-paste these for common scenarios:

### Minimal config

```toml
[versions]
rules_cc = "0.2.27"
```

### Map a custom library

```toml
[mappings.system_libraries]
mylib = "@mylib"
```

### Source archives

```toml
[strategy]
default = "source"

[mappings.known_packages.zlib]
version = "1.3.1"
url = "https://github.com/madler/zlib/releases/download/v1.3.1/zlib-1.3.1.tar.gz"
sha256 = "9a93b2b7dfdac77ceba5a558a580e74667dd6fede4585b91eefb60f03b72df23"
strip_prefix = "zlib-1.3.1"
build_system = "cmake"
out_static_libs = ["libz.a"]
```

### Mix providers

```toml
[strategy]
default = "system"

[strategy.overrides]
zlib = "source"
```

### CMake package mapping

```toml
[mappings.packages.OpenSSL]
target_pattern = "@openssl//:{component}"

[mappings.packages.OpenSSL.components]
SSL = "@openssl//:ssl"
Crypto = "@openssl//:crypto"
```

## Full reference

### `[versions]`

Pin Bazel dependency versions:

```toml
[versions]
rules_cc = "0.2.27"
platforms = "0.0.11"
rules_foreign_cc = "0.14.0"
googletest = "1.15.2"
google_benchmark = "1.9.1"
```

### `[strategy]`

Select `system`, `source`, or `bcr` for managed pkg-config dependencies:

```toml
[strategy]
default = "system"
bcr_fallback = "system" # system or source, for unresolved/skipped BCR packages

[strategy.overrides]
zlib = "source"

[strategy.bcr.version_pins]
zlib = "1.3.1.bcr.5"
```

A normalized CMake prefix override wins over package/catalog overrides, then the
default applies. `strategy.bcr.module_overrides` maps original module names to
replacement names; `strategy.bcr.skip_packages` selects fallback for listed
packages. Pins apply after module overrides. Replacements must provide the same
package/target layout. Unsupported strategy spellings fail planning, including
unused overrides. See [Dependency Strategies](/rebaze/concepts/dependency-strategies/)
for constraints, scope, and system compiler-flag limits.

### `[mappings]`

#### System libraries

Map `-l` flags to Bazel targets:

```toml
[mappings.system_libraries]
z = "@zlib"
ssl = "@openssl//:ssl"
crypto = "@openssl//:crypto"
gtest = "@googletest//:gtest"
```

#### Plain libraries

Map library names without `-l` prefix:

```toml
[mappings.plain_libraries]
gtest = "@googletest//:gtest"
boost = "@boost"
```

#### CMake packages

Map `find_package()` results:

```toml
[mappings.packages.Boost]
target_pattern = "@boost//:{component}"

[mappings.packages.Boost.components]
filesystem = "@boost//:filesystem"
system = "@boost//:system"
```

#### Implicit system libraries

Libraries to ignore (linked by default):

```toml
[mappings]
implicit_system_libs = ["pthread", "c", "m", "dl", "rt"]
```

#### Ignored libraries

Libraries to skip entirely:

```toml
[mappings]
ignored_libraries = ["fmt", "spdlog", "Threads::Threads"]
```

#### Transitive dependencies

Declare deps that pull in other deps:

```toml
[mappings.transitive_deps]
glib = ["pcre2", "libffi", "zlib"]
curl = ["zlib", "openssl"]
```

#### System linkopts

Reserved mapping data. The managed system wrapper currently uses the explicit
pkg-config observation; it does not consume these fallback settings:

```toml
[mappings.system_linkopts]
"glib-2.0" = ["-lglib-2.0"]
curl = ["-lcurl"]
```

### `[mappings.known_packages]`

Define active source builds. Entries require complete archive metadata and library
outputs; see [Build from Source](/rebaze/guides/source-builds/) for options,
transitives, and validation:

```toml
[mappings.known_packages.zlib]
version = "1.3.1"
url = "https://github.com/madler/zlib/releases/download/v1.3.1/zlib-1.3.1.tar.gz"
sha256 = "9a93b2b7dfdac77ceba5a558a580e74667dd6fede4585b91eefb60f03b72df23"
strip_prefix = "zlib-1.3.1"
build_system = "cmake"  # cmake | meson | autotools
pkg_config_packages = ["zlib"] # Used for system overrides of source transitives
build_options = ["-DBUILD_SHARED_LIBS=OFF"]
out_static_libs = ["libz.a"]
```

### `[build]`

Configure generated BUILD files:

```toml
[build]
default_visibility = "//visibility:public"
header_patterns = ["**/*.h", "**/*.hpp"]
default_cxx_standard = "17"
default_c_standard = "11"
module_version = "0.1.0"
```

#### Custom rules

Use your own rule implementations:

```toml
[build.rules]
library_rule = "my_cc_library"
binary_rule = "my_cc_binary"
test_rule = "my_cc_test"

[[build.rules.extra_loads]]
bzl = "@company//build:rules.bzl"
items = ["my_cc_library", "my_cc_binary"]
```

### `[filters]`

Filter platform-specific artifacts:

```toml
[filters]
excluded_source_extensions = ["rc", "res", "plist", "o", "obj"]
excluded_define_patterns = ["_WIN32", "__APPLE__", "_DEBUG"]
excluded_copt_patterns = ["/", "-O", "-g", "-std="]
excluded_include_patterns = ["/usr/", "/opt/"]
```

## Complete example

<Aside type="tip">
  See [rebaze.example.toml](https://github.com/albertocavalcante/rebaze/blob/main/rebaze.example.toml) for a valid configuration template. Explicit external mappings still require
  compatible module declarations in the generated project.
</Aside>

```toml
# rebaze.toml - Complete example

[versions]
rules_cc = "0.2.27"
rules_foreign_cc = "0.14.0"
googletest = "1.15.2"

[strategy]
default = "system"

[strategy.overrides]
zlib = "source"

[mappings.system_libraries]
z = "@zlib"
ssl = "@openssl//:ssl"
crypto = "@openssl//:crypto"

[mappings]
implicit_system_libs = ["pthread", "c", "m", "dl", "rt"]
ignored_libraries = ["Threads::Threads"]

[mappings.known_packages.zlib]
version = "1.3.1"
url = "https://github.com/madler/zlib/releases/download/v1.3.1/zlib-1.3.1.tar.gz"
sha256 = "9a93b2b7dfdac77ceba5a558a580e74667dd6fede4585b91eefb60f03b72df23"
strip_prefix = "zlib-1.3.1"
build_system = "cmake"
out_static_libs = ["libz.a"]

[build]
default_visibility = "//visibility:public"
default_cxx_standard = "17"

[filters]
excluded_source_extensions = ["rc", "res", "plist"]
excluded_define_patterns = ["_WIN32", "__APPLE__"]
```
