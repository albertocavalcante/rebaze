This tutorial walks through migrating a Gradle Java/Kotlin project to Bazel.

## What You'll Learn

- How to analyze a Gradle project
- How to handle multi-module projects
- How to map Gradle dependencies to Bazel

## Prerequisites

- A Gradle project with `build.gradle` or `build.gradle.kts`
- Bazel 9.x installed
- rebaze binary

## Project Structure

Consider a typical Gradle project:

<FileTree>
- myapp/
  - build.gradle.kts
  - settings.gradle.kts
  - app/
    - build.gradle.kts
    - src/main/java/...
  - lib/
    - build.gradle.kts
    - src/main/java/...
</FileTree>

With `settings.gradle.kts`:

```kotlin
rootProject.name = "myapp"
include("app", "lib")
```

<Steps>

1. **Analyze the project**

   ```bash
   rebaze analyze myapp/
   ```

   Output:
   ```
   Detected build systems: gradle
   ```

2. **Preview the migration**

   ```bash
   rebaze migrate myapp/ --dry-run
   ```

   Shows generated files:

   ```python
   # MODULE.bazel
   module(name = "myapp", version = "0.1.0")
   bazel_dep(name = "rules_java", version = "...")
   ```

   ```python
   # app/BUILD.bazel
   java_binary(
       name = "app",
       srcs = glob(["src/main/java/**/*.java"]),
       deps = ["//lib"],
   )
   ```

   ```python
   # lib/BUILD.bazel
   java_library(
       name = "lib",
       srcs = glob(["src/main/java/**/*.java"]),
       visibility = ["//visibility:public"],
   )
   ```

3. **Run the migration**

   ```bash
   rebaze migrate myapp/
   ```

4. **Validate**

   ```bash
   rebaze validate myapp/
   ```

   Or:

   ```bash
   cd myapp
   bazel build //...
   bazel test //...
   ```

</Steps>

## External Dependencies

Gradle dependencies are mapped to `rules_jvm_external`:

```kotlin
// build.gradle.kts
dependencies {
    implementation("com.google.guava:guava:32.1.3-jre")
    testImplementation("junit:junit:4.13.2")
}
```

Generates:

```python
# MODULE.bazel
maven = use_extension("@rules_jvm_external//:extensions.bzl", "maven")
maven.install(
    artifacts = [
        "com.google.guava:guava:32.1.3-jre",
        "junit:junit:4.13.2",
    ],
)
use_repo(maven, "maven")
```

```python
# BUILD.bazel
java_library(
    name = "lib",
    srcs = glob(["src/main/java/**/*.java"]),
    deps = ["@maven//:com_google_guava_guava"],
)
```

## Gradle to Bazel Mapping

| Gradle | Bazel |
|--------|-------|
| `implementation` | `deps` |
| `api` | `deps` + `exports` |
| `testImplementation` | test target `deps` |
| `compileOnly` | `neverlink = True` |
| `runtimeOnly` | `runtime_deps` |

## Current Limitations

<Aside type="caution">
Current Gradle support limitations:

- ✅ Java projects
- ✅ Multi-module projects
- ✅ Maven dependencies
- ⚠️ Kotlin projects (partial)
- ❌ Android projects
- ❌ Gradle plugins
</Aside>
