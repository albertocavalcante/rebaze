rebaze generates Bazel 9 files from supported CMake and Gradle project information.
It is in early development; review the output and validate your project's behavior.

## Build and preview

```bash
git clone https://github.com/albertocavalcante/rebaze.git
cd rebaze
bazel build //crates/rebaze-cli:rebaze
bazel run //crates/rebaze-cli:rebaze -- migrate /path/to/project --build-generator native --dry-run
```

Replace `/path/to/project` with an existing CMake or Gradle project. The native dry
run prints proposed files without writing or running build validation. See
[installation](/rebaze/getting-started/installation/) for prerequisites and a Cargo
build path, then follow the [quick start](/rebaze/getting-started/quickstart/).

## Support and development

CMake and Gradle have native generation paths. Maven migration and other source
formats are not implemented. Custom build logic, native CMake tests, and dependency
strategies still have gaps; see the [introduction](/rebaze/getting-started/introduction/).

For development, read the
[contributing guide](https://github.com/albertocavalcante/rebaze/blob/main/CONTRIBUTING.md),
[architecture](https://github.com/albertocavalcante/rebaze/blob/main/docs/architecture.md),
and [engineering roadmap](https://github.com/albertocavalcante/rebaze/blob/main/docs/engineering-roadmap.md).
