## Features

<CardGrid>
	<Card title="Fast Migration" icon="rocket">
		Analyze and migrate your project in seconds. No manual BUILD file writing required.
	</Card>
	<Card title="Smart Dependencies" icon="puzzle">
		Automatically maps CMake find_package() and Gradle dependencies to Bazel targets.
	</Card>
	<Card title="Configurable" icon="setting">
		Customize mappings, rules, and strategies via rebaze.toml configuration.
	</Card>
	<Card title="Hermetic Builds" icon="approve-check-circle">
		Optional source builds with rules_foreign_cc for fully reproducible builds.
	</Card>
</CardGrid>

## Supported Build Systems

| Source | Status | Notes |
|--------|--------|-------|
| CMake | ✅ Supported | Full parser + cmake-file-api integration |
| Gradle | ✅ Supported | Groovy and Kotlin DSL |
| Maven | 🔜 Planned | Detection only |

## Quick Example

```bash
# Analyze your project
rebaze analyze /path/to/project
# Output: Detected build systems: cmake

# Migrate to Bazel
rebaze migrate /path/to/project

# Validate the migration
rebaze validate /path/to/project
```
