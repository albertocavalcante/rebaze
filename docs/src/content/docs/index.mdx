## Install

<Tabs>
<TabItem label="Homebrew">
```bash
# Add the tap and install
brew tap albertocavalcante/tap
brew install albertocavalcante/tap/rebaze

# Migrate your project
rebaze migrate /path/to/your/project
```
</TabItem>
<TabItem label="Homebrew (Nightly)">
```bash
# Requires GitHub token for private repo access
export HOMEBREW_GITHUB_API_TOKEN="$(gh auth token)"

# Add the tap and install nightly (prebuilt binaries)
brew tap albertocavalcante/tap
brew install albertocavalcante/tap/rebaze-nightly

# Migrate your project
rebaze migrate /path/to/your/project
```
</TabItem>
<TabItem label="From Source">
```bash
# Clone and build with Bazel
git clone https://github.com/albertocavalcante/rebaze && cd rebaze
bazel build //crates/rebaze-cli:rebaze

# Run directly
bazel run //crates/rebaze-cli:rebaze -- migrate /path/to/your/project
```
</TabItem>
</Tabs>

That's it. Your CMake or Gradle project now has Bazel build files.

## Features

<CardGrid>
	<Card title="Fast Migration" icon="rocket">
		Analyze and migrate your project in seconds. No manual BUILD file writing required.
	</Card>
	<Card title="Smart Dependencies" icon="puzzle">
		Automatically maps CMake find_package() and Gradle dependencies to Bazel targets.
	</Card>
	<Card title="Configurable" icon="setting">
		Customize mappings, rules, and strategies via rebaze.toml configuration.
	</Card>
	<Card title="Hermetic Builds" icon="approve-check-circle">
		Optional source builds with rules_foreign_cc for fully reproducible builds.
	</Card>
</CardGrid>

## Quick Example

<Tabs>
<TabItem label="CMake">
**Before:** `CMakeLists.txt`
```cmake
cmake_minimum_required(VERSION 3.14)
project(myapp)

find_package(ZLIB REQUIRED)
add_library(mylib src/lib.cpp)
target_link_libraries(mylib ZLIB::ZLIB)
add_executable(myapp src/main.cpp)
target_link_libraries(myapp mylib)
```

**After:** Run `rebaze migrate .`

```python
# MODULE.bazel
module(name = "myapp", version = "0.1.0")
bazel_dep(name = "rules_cc", version = "0.1.1")
bazel_dep(name = "zlib", version = "1.3.1")
```

```python
# BUILD.bazel
load("@rules_cc//cc:defs.bzl", "cc_binary", "cc_library")

cc_library(
    name = "mylib",
    srcs = ["src/lib.cpp"],
    deps = ["@zlib"],
)

cc_binary(
    name = "myapp",
    srcs = ["src/main.cpp"],
    deps = [":mylib"],
)
```
</TabItem>
<TabItem label="Gradle">
**Before:** `build.gradle`
```groovy
plugins {
    id 'java'
}
dependencies {
    implementation 'com.google.guava:guava:32.1.3-jre'
    testImplementation 'junit:junit:4.13.2'
}
```

**After:** Run `rebaze migrate .`

```python
# MODULE.bazel
module(name = "myapp", version = "0.1.0")
bazel_dep(name = "rules_java", version = "7.4.0")
bazel_dep(name = "rules_jvm_external", version = "6.0")
```

```python
# BUILD.bazel
load("@rules_java//java:defs.bzl", "java_binary", "java_library")

java_library(
    name = "lib",
    srcs = glob(["src/main/java/**/*.java"]),
    deps = ["@maven//:com_google_guava_guava"],
)
```
</TabItem>
</Tabs>

<Aside type="tip">
Run `rebaze migrate --dry-run` to preview changes before writing files.
</Aside>
