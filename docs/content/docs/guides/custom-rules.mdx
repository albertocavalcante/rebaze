---
title: Use Custom Bazel Rules
description: How to configure rebaze to generate custom rule calls instead of cc_library
---

Organizations often have custom Bazel rules that wrap `cc_library`, `cc_binary`, etc. with additional functionality. Rebaze can generate calls to your custom rules instead.

## Why Custom Rules?

Custom rules can:
- Enforce coding standards
- Add default compiler flags
- Integrate with internal tooling
- Provide consistent build configuration

## Configure Custom Rules

In `rebaze.toml`:

```toml
[build.rules]
library_rule = "my_cc_library"
binary_rule = "my_cc_binary"
test_rule = "my_cc_test"

[[build.rules.extra_loads]]
bzl = "@mycompany//build:rules.bzl"
items = ["my_cc_library", "my_cc_binary", "my_cc_test"]
```

## Generated Output

Instead of:

```python
load("@rules_cc//cc:defs.bzl", "cc_library", "cc_binary")

cc_library(
    name = "mylib",
    srcs = ["lib.cpp"],
)

cc_binary(
    name = "myapp",
    srcs = ["main.cpp"],
    deps = [":mylib"],
)
```

Rebaze generates:

```python
load("@rules_cc//cc:defs.bzl", "cc_library", "cc_binary")
load("@mycompany//build:rules.bzl", "my_cc_library", "my_cc_binary")

my_cc_library(
    name = "mylib",
    srcs = ["lib.cpp"],
)

my_cc_binary(
    name = "myapp",
    srcs = ["main.cpp"],
    deps = [":mylib"],
)
```

## Example: Spotify-Style Rules

Spotify's approach uses custom rules for all targets:

```toml
[build.rules]
library_rule = "spotify_cc_library"
binary_rule = "spotify_cc_binary"
test_rule = "spotify_cc_test"

[[build.rules.extra_loads]]
bzl = "@spotify//build:cc.bzl"
items = ["spotify_cc_library", "spotify_cc_binary", "spotify_cc_test"]
```

## Multiple Load Statements

You can add multiple load statements:

```toml
[[build.rules.extra_loads]]
bzl = "@mycompany//build:cc.bzl"
items = ["my_cc_library", "my_cc_binary"]

[[build.rules.extra_loads]]
bzl = "@mycompany//build:test.bzl"
items = ["my_cc_test"]
```

## Partial Customization

You can customize only some rules:

```toml
[build.rules]
# Use custom library rule
library_rule = "my_cc_library"
# Keep standard binary and test rules
binary_rule = "cc_binary"
test_rule = "cc_test"

[[build.rules.extra_loads]]
bzl = "@mycompany//build:rules.bzl"
items = ["my_cc_library"]
```
