description: Step-by-step guide to migrating a Gradle project to Bazel
---

This tutorial walks through migrating a Gradle Java/Kotlin project to Bazel.

## What You'll Learn

- How to analyze a Gradle project
- How to handle multi-module projects
- How to map Gradle dependencies to Bazel

## Prerequisites

- A Gradle project with `build.gradle` or `build.gradle.kts`
- Bazel 9.x installed
- rebaze binary

## Step 1: Analyze the Project

Consider a typical Gradle project:

```
myapp/
├── build.gradle.kts
├── settings.gradle.kts
├── app/
│   ├── build.gradle.kts
│   └── src/main/java/...
└── lib/
    ├── build.gradle.kts
    └── src/main/java/...
```

With `settings.gradle.kts`:

```kotlin
rootProject.name = "myapp"
include("app", "lib")
```

Analyze it:

```bash
rebaze analyze myapp/
```

Output:
```
Detected build systems: gradle
```

## Step 2: Preview the Migration

```bash
rebaze migrate myapp/ --dry-run
```

This shows the generated files:

```
--- MODULE.bazel ---
module(
    name = "myapp",
    version = "0.1.0",
)

bazel_dep(name = "rules_java", version = "...")

--- BUILD.bazel ---
# Root BUILD file

--- app/BUILD.bazel ---
java_binary(
    name = "app",
    srcs = glob(["src/main/java/**/*.java"]),
    deps = ["//lib"],
)

--- lib/BUILD.bazel ---
java_library(
    name = "lib",
    srcs = glob(["src/main/java/**/*.java"]),
    visibility = ["//visibility:public"],
)
```

## Step 3: Run the Migration

```bash
rebaze migrate myapp/
```

## Step 4: Handle External Dependencies

Gradle dependencies are mapped to Bazel's `rules_jvm_external`:

```kotlin
// build.gradle.kts
dependencies {
    implementation("com.google.guava:guava:32.1.3-jre")
    testImplementation("junit:junit:4.13.2")
}
```

Generates in `MODULE.bazel`:

```python
maven = use_extension("@rules_jvm_external//:extensions.bzl", "maven")
maven.install(
    artifacts = [
        "com.google.guava:guava:32.1.3-jre",
        "junit:junit:4.13.2",
    ],
)
use_repo(maven, "maven")
```

And in `BUILD.bazel`:

```python
java_library(
    name = "lib",
    srcs = glob(["src/main/java/**/*.java"]),
    deps = [
        "@maven//:com_google_guava_guava",
    ],
)

java_test(
    name = "test",
    srcs = glob(["src/test/java/**/*.java"]),
    deps = [
        ":lib",
        "@maven//:junit_junit",
    ],
)
```

## Step 5: Validate

```bash
rebaze validate myapp/
```

Or:

```bash
cd myapp
bazel build //...
bazel test //...
```

## Gradle Features Mapping

| Gradle | Bazel |
|--------|-------|
| `implementation` | `deps` |
| `api` | `deps` + `exports` |
| `testImplementation` | test target `deps` |
| `compileOnly` | Handled via `neverlink` |
| `runtimeOnly` | `runtime_deps` |

## Limitations

Current Gradle support:
- ✅ Java projects
- ✅ Multi-module projects
- ✅ Maven dependencies
- ⚠️ Kotlin projects (partial)
- ❌ Android projects (not yet)
- ❌ Gradle plugins (not migrated)
