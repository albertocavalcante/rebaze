rebaze is a CLI tool that migrates projects from CMake and Gradle to Bazel.

## Installation

Build from source using Bazel:

```bash
bazel build //crates/rebaze-cli:rebaze
```

The binary will be at `bazel-bin/crates/rebaze-cli/rebaze`.

## Quick Start

### 1. Analyze your project

First, detect which build system your project uses:

```bash
rebaze analyze /path/to/project
```

Output:
```
Detected build systems: cmake
```

### 2. Migrate to Bazel

Generate Bazel build files:

```bash
rebaze migrate /path/to/project
```

This generates:
- `MODULE.bazel` - Module definition with dependencies
- `BUILD.bazel` - Build targets
- `.bazelversion` - Pins Bazel 9.x
- `.bazelrc` - Build configuration

### 3. Validate the migration

Verify the generated files build successfully:

```bash
rebaze validate /path/to/project
```

## Supported Build Systems

| Source | Status | Notes |
|--------|--------|-------|
| CMake | Supported | Full parser + cmake-file-api integration |
| Gradle | Supported | Groovy and Kotlin DSL |
| Maven | Detection only | Migration planned |

## Configuration

Create a `rebaze.toml` in your project root to customize the migration:

```toml
[versions]
rules_cc = "0.1.1"
googletest = "1.15.2"

[mappings.system_libraries]
z = "@zlib"
ssl = "@openssl"

[strategy]
default = "system"
```

See the [Configuration Reference](/docs/reference/config) for all options.

## Requirements

- Bazel 9.x
- For CMake projects: CMake 3.14+ (optional, for cmake-file-api)
